# openspec/

Spec-driven change workflow (schema: `spec-driven`). See `README.md` for layout and rules.

- `specs/` — accepted capability specs (current truth).
- `changes/` — proposed/in-progress changes (`proposal.md`, `design.md`, `tasks.md`, `specs/`); `changes/archive/` holds completed ones.

Validate with `openspec validate --all`. Keep specs focused on testable capabilities derived from real data formats and operator workflows; don't copy general docs here.
