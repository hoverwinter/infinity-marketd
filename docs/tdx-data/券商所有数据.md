## 文件格式说明

大多数包内文件为 `.day`，普通证券和指数日线通常按 32 bytes 固定记录解析。扩展行情也沿用 `.day` 后缀，但文件名前带市场号，例如 `8#`、`9#`、`31#`、`33#`、`34#`、`38#`、`44#`、`62#`。

宏观指标包中的价位字段需要按 `float32` 理解。抽样 `38#1_GDP.day` 后，记录日期为年度末日期，开高低收四个浮点值相同，例如 `19521231 -> 680.2`，适合建模为宏观指标时间序列，而不是证券 OHLCV。
