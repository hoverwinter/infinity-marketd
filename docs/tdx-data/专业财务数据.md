# 专业财务数据

来源页面：`https://www.tdx.com.cn/article/stockfin.html`

## 页面定位

该页面提供通达信专业财务数据相关的两个 ZIP 包。官方说明适用于有增强功能集的券商通达信版本和通达信个人收费版本，主要供公式、选股、预警、股票池和指标排序等功能使用。

官方使用方法是下载后放到客户端 `vipdoc/cw` 目录下，直接解压到当前文件夹覆盖。

## 财务数据包 `tdxfin.zip`

包内结构：

| Kind | Count | Example |
| --- | ---: | --- |
| 财务报告期 `.dat` | 148 | `gpcw20251231.dat` |
| 同名压缩副本 `.zip` | 148 | `gpcw20251231.zip` |
| 清单文件 | 1 | `gpcw.txt` |

`gpcw.txt` 是文件名、MD5、大小清单。`gpcwYYYYMMDD.dat` 是按报告期组织的全市场财务数据，例如 `gpcw20251231.dat` 表示 2025 年年报期数据。同名 `.zip` 内部压缩的是同一个 `.dat`。

这类数据对应通达信专业财务函数和 TdxQuant 的 `get_financial_data` 使用场景，内容包括报告期财务项目和衍生指标，例如每股收益、每股净资产、净资产收益率、资产负债、营收利润、现金流、股本、股东户数、机构持股、业绩预告/快报等。

## 股票数据包 `tdxgp.zip`

包内结构：

| Kind | Count | Example |
| --- | ---: | --- |
| 北交所股票数据 | 567 | `gpbj920000.dat` |
| 上交所股票数据 | 3800 | `gpsh600000.dat` |
| 深交所股票数据 | 3192 | `gpsz000001.dat` |
| 清单/校验文件 | 2 | `gpszsh.txt`、`gpszsh.local` |

`gpszsh.txt` 是文件名、MD5、大小清单，`gpszsh.local` 是同一批文件的本地校验映射。

单个 `gp{market}{code}.dat` 是按证券拆分的历史扩展指标数据，不是日 K 线行情。抽样文件显示其记录为固定 13 bytes：

| Offset | Size | Type | Meaning |
| --- | ---: | --- | --- |
| 0 | 1 | `uint8` | 指标类型号 |
| 1 | 4 | `uint32` | 日期，`YYYYMMDD` |
| 5 | 4 | `float32` | 数值 1 |
| 9 | 4 | `float32` | 数值 2 或补充字段 |

这类数据对应通达信股票交易/扩展指标函数和 TdxQuant 的 `get_gpjy_value` 使用场景，内容包括股东户数、龙虎榜、融资融券、大宗交易、增减持、陆股通持股、涨停/跌停、总市值、股票质押、股息率、首次涨停时间、竞价数据、人气排名、分红送转、股票评分和评级系数等。

## 使用边界

`tdxfin.zip` 和 `tdxgp.zip` 是通达信客户端专用二进制缓存，不是通用 CSV/JSON 数据源。解析实现应先按文件清单和固定记录结构建立 fixtures，再逐步补齐字段类型号与通达信函数字段之间的映射。
