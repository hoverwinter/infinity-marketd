# 专业财务数据

来源页面：`https://www.tdx.com.cn/article/stockfin.html`

## 页面定位

该页面提供通达信专业财务数据相关的两个 ZIP 包。官方说明适用于有增强功能集的券商通达信版本和通达信个人收费版本，主要供公式、选股、预警、股票池和指标排序等功能使用。

官方使用方法是下载后放到客户端 `vipdoc/cw` 目录下，直接解压到当前文件夹覆盖。

## 财务数据包 `tdxfin.zip`

包内结构：

| Kind | Count | Example |
| --- | ---: | --- |
| 财务报告期 `.dat` | 148 | `gpcw20251231.dat` |
| 同名压缩副本 `.zip` | 148 | `gpcw20251231.zip` |
| 清单文件 | 1 | `gpcw.txt` |

`gpcw.txt` 是文件名、MD5、大小清单。`gpcwYYYYMMDD.dat` 是按报告期组织的全市场财务数据，例如 `gpcw20251231.dat` 表示 2025 年年报期数据。同名 `.zip` 内部压缩的是同一个 `.dat`。`marketd` 优先解析包内直接提供的 `.dat`，也支持只存在同名 `.zip` 时从内层 `.dat` 读取。

这类数据对应通达信专业财务函数和 TdxQuant 的 `get_financial_data` 使用场景，内容包括报告期财务项目和衍生指标，例如每股收益、每股净资产、净资产收益率、资产负债、营收利润、现金流、股本、股东户数、机构持股、业绩预告/快报等。

确认的 `.dat` 结构来自 pytdx/mootdx 的 `HistoryFinancialReader` / `FinancialReader`：

| Offset | Size | Type | Meaning |
| --- | ---: | --- | --- |
| 0 | 2 | `int16` | 文件版本/标记 |
| 2 | 4 | `uint32` | 报告期，`YYYYMMDD` |
| 6 | 2 | `uint16` | 股票索引记录数 |
| 8 | 4 | `uint32` | 索引记录长度，当前为 11 |
| 12 | 4 | `uint32` | 单股票财务字段区字节数，字段数为该值除以 4 |
| 16 | 4 | `uint32` | 保留 |
| 20 | `count * 11` | `<6s1c1L>` | 股票代码、保留字节、该股票字段区偏移 |
| `offset` | `report_size` | `float32[]` | `FN1..FNn` 财务字段值 |

字段字典保存在 `internal/tdx/finance/metadata/financial_items.csv`，`item_id=1` 对应 TdxQuant/mootdx 的 `FN1` / `col1`，`report_date` 单独来自文件头，不作为财务 item 写入 raw facts。

导入命令：

```bash
go run ./cmd/marketd import-tdx-fin --file data/tdxfin.zip --dry-run
go run ./cmd/marketd import-tdx-fin --file data/tdxfin.zip
```

### 远程单报告包工作流

`marketd` 也支持类似 `mootdx.affair` 的远程 `gpcw` 文件工作流。默认远程目录是 `https://data.tdx.com.cn/tdxfin/`，清单文件为 `gpcw.txt`，每行格式为：

```text
filename,md5,size
```

常用命令：

```bash
go run ./cmd/marketd tdx-fin-files
go run ./cmd/marketd tdx-fin-fetch --filename gpcw20251231.zip --dir data/tdxfin
go run ./cmd/marketd tdx-fin-parse --file data/tdxfin/gpcw20251231.zip
```

`tdx-fin-fetch` 会先读取远程 `gpcw.txt`，再按清单校验下载文件的大小和 MD5。目标文件已存在且校验匹配时会跳过下载。需要全量拉取清单中所有报告期时必须显式指定：

```bash
go run ./cmd/marketd tdx-fin-fetch --all --dir data/tdxfin
```

`tdx-fin-parse` 是 parse-only/dry-run 命令，只解析并打印汇总，不打开 ClickHouse，不写 raw facts。确认无误后，如需落库，仍使用显式导入命令：

```bash
go run ./cmd/marketd import-tdx-fin --file data/tdxfin/gpcw20251231.zip
```

## 股票数据包 `tdxgp.zip`

包内结构：

| Kind | Count | Example |
| --- | ---: | --- |
| 北交所股票数据 | 567 | `gpbj920000.dat` |
| 上交所股票数据 | 3800 | `gpsh600000.dat` |
| 深交所股票数据 | 3192 | `gpsz000001.dat` |
| 清单/校验文件 | 2 | `gpszsh.txt`、`gpszsh.local` |

`gpszsh.txt` 是文件名、MD5、大小清单，`gpszsh.local` 是同一批文件的本地校验映射。

单个 `gp{market}{code}.dat` 是按证券拆分的历史扩展指标数据，不是日 K 线行情。抽样文件显示其记录为固定 13 bytes：

| Offset | Size | Type | Meaning |
| --- | ---: | --- | --- |
| 0 | 1 | `uint8` | 指标类型号 |
| 1 | 4 | `uint32` | 日期，`YYYYMMDD` |
| 5 | 4 | `float32` | 数值 1 |
| 9 | 4 | `float32` | 数值 2 或补充字段 |

这类数据对应通达信股票交易/扩展指标函数和 TdxQuant 的 `get_gpjy_value` 使用场景，内容包括股东户数、龙虎榜、融资融券、大宗交易、增减持、陆股通持股、涨停/跌停、总市值、股票质押、股息率、首次涨停时间、竞价数据、人气排名、分红送转、股票评分和评级系数等。

字段字典保存在 `internal/tdx/finance/metadata/gp_metrics.csv`，来源为通达信量化平台 `get_gpjy_value` 官方字段表，覆盖 `GP01..GP46`。`metric_type=1` 对应 `GP01`。

导入命令：

```bash
go run ./cmd/marketd import-tdx-gp --file data/tdxgp.zip --dry-run
go run ./cmd/marketd import-tdx-gp --file data/tdxgp.zip
```

## 写入表

`tdxfin.zip` 写入 `infinity_market.a_share_financial_raw_items`：

```text
market + symbol + report_date + item_id -> value
```

`tdxgp.zip` 写入 `infinity_market.a_share_gp_metric_values`：

```text
market + symbol + metric_type + event_date -> value1/value2
```

导入会先把 repo 内字典同步到 ClickHouse 字典表，再写 raw facts。`--dry-run` 只解析、校验和汇总，不打开 ClickHouse，不写 raw facts，也不写字典表。

## 使用边界

`tdxfin.zip` 和 `tdxgp.zip` 是通达信客户端专用二进制缓存，不是通用 CSV/JSON 数据源。当前实现只导入 raw facts 和字典，不生成财务派生宽表；后续宽表应由显式 refresh job 从 raw facts 生成。

pytdx/mootdx 中涉及的 `trade.dll` / `pytdx.trade` 交易能力不属于 `marketd` 数据导入范围，本项目不实现自动交易接口。
