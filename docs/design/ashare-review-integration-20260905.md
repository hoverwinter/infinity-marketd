## 写入保护

- `internal/ingest/limit_review.go`：增加 `enrich_existing`，读取完整当前行后只允许补空原因、空/未分类题材。其余字段或已有非空归因变化，整批拒绝；缺事件也拒绝。
- `internal/consoleops/limit_review.go`：HTTP 预览和执行均使用上述保护；材料端点不能使用无限制 upsert。
- `internal/cli/limit_review.go`：读当前行通过 `--read-url` HTTP querier，不直接读 ClickHouse。操作员确需替换事实时必须明确 `--allow-fact-replacement`；普通历史快照不能覆盖已有事件日期。
- `internal/ingest/limit_review_ths.go`：Go THS 刷新保留既有归因、题材、标签以及供应商未返回的可选事件值；操作策略及过滤范围写入现有 ops params，不加事实来源列。
- `internal/querier/limit_review.go`：只做有界 Repository/HTTP DTO 转换，没有新增 SQL 位置、表或查询服务。

直接经 Go 校验采集的 THS/TDX 数据与“经 Go 导入的旧 JSON”不是同等来源证明。现存 2,482 个历史 replay 输入有 `missing_bars`，近期 112 个 THS 快照也不是本次重新采集的完整池证明。数据库存在某日记录不意味着当天池已全量。独立进程仍须串行写入，同一进程锁不构成分布式事务。
